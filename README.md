## 📖 About The Project

This project was built with one clear goal: **to demonstrate the real power of Bootstrap**. Rather than writing complex custom CSS from scratch, Bootstrap's grid system, components, and utilities were used to rapidly build a clean, responsive, and professional landing page — proving that Bootstrap alone can produce production-ready results.

The page is designed in Persian (RTL layout) and uses the **Vazir** font family for crisp Persian typography across all screen sizes.

---

## ✨ Features

- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ RTL (Right-to-Left) layout support for Persian content
- ✅ Sticky navigation bar with dropdown menu
- ✅ Hero section with call-to-action buttons
- ✅ Feature cards section
- ✅ Pricing table with three tiers (Basic, Advanced, Professional)
- ✅ Image carousel / gallery slider
- ✅ Contact form section
- ✅ Brand logo strip section
- ✅ Multi-column footer with navigation links
- ✅ Smooth scroll and interactive components via Bootstrap JS

## 🚀 Getting Started

### Prerequisites

All you need is a web browser — no build tools or installations required.

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/novixweb/bootstrap-landing-page.git

# 2. Navigate to the project folder
cd bootstrap-landing-page

# 3. Open index.html in your browser
open index.html
```

Or simply drag and drop `index.html` into your browser.
